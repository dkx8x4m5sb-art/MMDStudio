# MMD Studio

原生 iOS 的 PMX 模型浏览器与 MMD 动作播放器。SwiftUI + Metal 渲染，PMX/PMD/VMD 解析、蒙皮、物理全部在本机完成，运行时不需要网络。

- 部署目标 iOS 17.0，用 iOS 27 SDK 构建
- 工程无 Swift Package 依赖；物理使用仓库内 vendored 的 Bullet 3.25（见[开源与引用](#开源与引用)）

## 构建

用 Xcode 打开 `MMDStudio.xcodeproj`，在 target **MMDStudio** 的 *Signing & Capabilities* 选择自己的 Team（上架前把 Bundle Identifier 从 `com.mmdstudio.app` 改掉），选设备后 Run。

命令行出包：

```bash
./scripts/build_ipa.sh                 # 未签名 IPA
ADHOC_SIGN=1 ./scripts/build_ipa.sh    # 追加 ad-hoc 签名
```

产物在 `build/`，版本号取自工程，不在脚本里重复维护。

## 功能

### 模型库

- 从「文件」导入模型文件夹、单个 `.pmx`/`.pmd` 或 `.zip`；ZIP 自动解压并递归识别所有 PMX，保留 `tex/`、`sph/` 等贴图子目录
- 压缩包缺少中央目录（流式打包、下载中断）时改为逐个文件头恢复，能救回的文件照常导入；RAR/7z 改后缀的包会直接说明需要先解压
- 按角色归档：文件夹名取模型自己的名字而不是压缩包名，所以「绳匠」包里的玲和哲会分成两个文件夹；同一角色的多套服装（白/黑/泳装）即使来自不同压缩包也合并到同一个文件夹，行内只显示款式名
- 武器与道具归到所属角色下，行内标注为「武器」「扇子」；包里只有一个角色时其余模型自动跟随该角色
- 逻辑文件夹分组、批量移动、重命名、删除；包内文件页可查看真实目录、追加贴图、删除单个文件
- 打开角色时可自动挂载同包内的小型道具

### 动作库

- 动作包只导入一次，保存在应用自己的动作库中，按内容哈希去重；重复导入同一个 ZIP 不会多占空间
- 动作与镜头分区：`Motion_*.vmd` 进「动作」，`Camera_*.vmd` 这类纯相机文件进「镜头」
- 进入画布后从动作库任选动作与镜头，不必重复导入；从模型包打开时自动选用与当前模型骨骼匹配度最高的那一版动作
- 关闭画布时清理旧版按次导入留下的临时目录

### 画布

- 轨道相机：单指旋转、双指平移、捏合缩放、双击重置，按包围盒自动取景
- 底栏固定六格、一屏看全：动作 / 材质 / 表情 / 灯光 / 物理 / 更多；不再横向滚动去找功能
- 物理与更多打开的是画布内浮层（可滚动、可停留），不是系统下拉菜单：菜单所在视图被性能统计刷新时会不断重建，表现为闪烁和滚动位置弹回顶部
- 物理浮层直接切四档模式、开关刚体与碰撞球显示，不用进出设置
- 画布右上角常驻「网格 / 骨架 / 刚体」开关，点一下即生效
- 材质、表情、灯光、骨骼、贴图、场景、渲染、设置等检查器统一为半高面板；面板弹出时画面上移并轻微缩小，模型始终完整可见
- 有动作时播放条右侧的「播放」浮层：循环、速度、VMD 相机、换动作、移除动作
- 设置按「画面 / 显示 / 物理 / 动作 / 系统」分区，切一次只显示相关参数
- 骨骼选择与 RGB 轴变换，手动旋转/位移叠加在 VMD 动作之上
- VPD 静态姿势导入
- 表情 Morph 滑杆与 VMD 变形关键帧叠加，组 Morph 自动联动
- 音频驱动口型默认关闭；动作本身带口型表情轨道时自动关闭并提示，避免两层口型叠加

### 渲染

- PMX 2.0/2.1，UTF-16LE 与 UTF-8 文本；BDEF1/2/4、QDEF、SDEF 权重，GPU 蒙皮
- 卡通分层（多段 ramp、阴影色相偏移、阶梯高光、轮廓光、皮肤透光）与写实两种风格
- 球面贴图（乘法/加法）、基础贴图、透明混合、Alpha 裁切、双面材质、屏幕空间描边
- 渐变摄影棚背景、接触阴影、可选地面网格、骨骼线框叠加

### 物理

- 物理模式四档：关闭 / 自动 / 摆动（裙·发）/ PMX 刚体；**自动**在模型带可用刚体链时走 Bullet，否则退回摆动
- 直接读取 PMX 的刚体与 6DOF 关节跑 Bullet，作者调好的质量、阻尼、摩擦与限位原样生效
- 碰撞体从网格实测生成多球链（按蒙皮权重分桶、按骨段取半径），不再用一根胶囊包住整条腿
- 摆动模式里每节链按 40% / 75% / 100% 三处采样做碰撞，撞到后衰减角速度，减少裙摆从大腿中间穿过去
- 弹簧刚度随锚点速度提高：转身、起跑时链节更快贴回动画剪影，滞后和穿模同时减少
- 「惯性」滑杆接的是锚点加速度，起步/急停时裙摆会先被甩出去再回位
- 无刚体的模型按骨骼链补充弹簧解算，链按「路径」而非子树构建，避免把相邻裙板钉在一起
- 面部骨（目/眉/口/舌等）与核心人体骨即使绑定了刚体也不会被物理写回，只保留碰撞
- **显示刚体 / 显示碰撞球**：橙=动态刚体、青=骨骼跟随、灰=静止绑定（半透明）；绿色球是摆动模式实际使用的碰撞体，用来对照「模型有刚体但裙子还是穿」的位置
- 刚体线框按「骨骼当前矩阵 × 绑定矩阵的逆」摆放，位置与模型严丝合缝；静止刚体不再抢视觉
- 骨骼位置按 PMX 的绝对坐标换算成局部偏移再累加：以前直接把绝对值当偏移，祖先被重复计算，碰撞球整片飘到头顶上方，弹簧链锚点也跟着跑偏
- 导入的场景背景图按原方向铺满画面（不再上下颠倒）

### 导出

- 单帧 PNG 保存到相册
- 引擎内录屏（不含界面元素）
- 按 VMD 时间轴导出 MP4；按像素率自动选择 HEVC 或 H.264，并显示渲染/编码耗时
- 分辨率与帧率可选，导出时物理按固定步长推进，保证每次结果一致

### 存储与文件管理

- 概览显示应用总占用、四类明细（模型/导出/素材/缓存）、设备可用与总容量
- 一键清理临时文件、Caches、日志与崩溃残留的临时视频，并报告释放量
- 每个目录可展开为真实文件列表（按时间倒序、显示大小），支持滑动删除、多选、分享
- 所有删除都校验路径，只作用于应用自己的沙盒目录

### 日志

- 运行日志按类别记录（General / Motion / Physics / Scene / Bones 等），可在设置里查看与清空

## 已知问题

- **4K 60fps**：H.264 硬件编码器在 4K 下封顶 30fps，需要 60fps 时会切到 HEVC；设备不支持 HEVC 硬编时只能 30fps
- **足 IK**：默认关闭（设置里「VMD / PMX IK 求解」可开），依赖足 IK 的动作在关闭时会滑步
- **动作重定向**：按骨骼名、别名表与截断前缀匹配，非标准命名的模型会有部分轨道匹配不上；映射比例显示在动作设置页
- **刚体数量大**的模型（250+ 刚体、400+ 关节）在中低端设备上可能掉帧
- **面部与四肢刚体**不再驱动骨骼：正常动作不受影响，但完全依赖刚体着地的脚部不会跟随
- **PMX 2.1 软体**未实现，软体部分按骨骼链弹簧近似
- 贴图解码依赖系统 ImageIO，极少数旧格式（如 16bit TGA）可能显示异常
- 部分分享包实际是 RAR/7z 改成了 `.zip` 后缀，iOS 没有内置解压，需要先在「文件」里解压成文件夹再导入
