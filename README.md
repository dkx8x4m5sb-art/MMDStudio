# MMD Studio

原生 iOS 的 PMX 模型浏览、编辑与 MMD 动作播放器。使用 SwiftUI + Metal 与自研渲染管线，全部解析与渲染在本机完成，不依赖任何第三方库，运行时无网络请求。

> 部署目标 iOS 17.0（用 iOS 27 SDK 构建，可在 iOS 27 上运行）。源码不含任何版本判断，纯 SwiftUI + Metal 实现。

## 构建与运行

源码直接放在仓库里（不再以 zip 形式提交），CI 使用 GitHub Actions 的 `xcode-27` 镜像（Xcode 27.2 + iOS 27.2 SDK）构建未签名 IPA。

本地构建：

1. 用 Xcode 打开 `MMDStudio.xcodeproj`（无需解析任何 Swift Package，工程没有第三方依赖）。
2. 在 target **MMDStudio** 的 *Signing & Capabilities* 中选择你的 Team；要上架请把 Bundle Identifier 从 `com.mmdstudio.app` 改掉。
3. Scheme 选 **MMDStudio**，设备选 iPhone 或 iPad，Run。

命令行出包（未签名 / ad-hoc）：

```bash
./scripts/build_ipa.sh                 # 未签名 IPA，适合 TrollStore / AltStore / 侧载
ADHOC_SIGN=1 ./scripts/build_ipa.sh    # 追加 ad-hoc 签名
```

产物在 `build/`，版本号直接从工程读取，不需要在脚本里改第二份。

## 功能

- **导入**：从「文件」App 选择整个 PMX/PMD 模型文件夹、单个 `.pmx`/`.pmd` 或 `.zip`。ZIP 会自动解压并递归识别所有 PMX，保留 `tex/`、`sph/` 等贴图子目录；只识别到一个模型时会自动打开并加载贴图。
- **浏览**：轨道相机（单指旋转、双指平移、捏合缩放、双击重置），自动按模型包围盒取景；渐变摄影棚背景、柔和接触阴影、可选网格、骨骼线框叠加。
- **PMX 渲染**：PMX 2.0 / 2.1；UTF-16LE / UTF-8 文本；BDEF1 / BDEF2 / BDEF4 / QDEF / **SDEF** 权重；GPU 蒙皮；原神式卡通分层（多段 ramp 硬阴影、阴影色相偏移、阶梯高光、受光侧轮廓光、皮肤透光）；球面贴图（乘法 / 加法）；基础贴图；透明混合；屏幕空间等宽描边；Alpha 裁切；双面材质。
- **材质编辑**：漫反射颜色、不透明度、显示开关、双面、地面阴影、基础贴图开关、卡通渐变开关、球面模式、描边颜色/宽度/开关、恢复单个或全部材质默认值。
- **顶点变形**：顶点 Morph 与组 Morph 的滑杆；可与 VMD 的 Morph 关键帧叠加。
- **骨骼编辑**：搜索骨骼；手动 X/Y/Z 旋转（角度）；单根或全部归零；选中骨骼在视图中高亮，并显示 IK 目标连线。
- **VMD 动作**：骨骼关键帧（位置/四元数/贝塞尔补间）、Morph 关键帧、相机关键帧；30 FPS 播放、拖动进度、循环、0.5x–2x 速度、VMD 相机开关、替换/移除动作。v9 修复了把“秒”误当“帧”的时长上限，464 帧的 IRIS OUT 会完整播放 15.47 秒；VMD/ZIP 导入时自动匹配同名 WAV 并同步播放。
- **模型库与文件（v9）**：按导入压缩包分组，支持创建逻辑模型文件夹、多选分组、重命名/删除；包内文件页可查看实际目录、追加模型/配饰/贴图、删除单文件。逻辑分组不移动包内贴图路径。
- **武器与配饰（v9）**：打开角色包时按文件名与骨骼/顶点规模识别同包配饰，自动载入并绑定到建议骨骼；也可从 PMX、文件夹或 ZIP 单独导入。配饰作为独立 PMX 场景物件渲染，可绑定任意角色骨骼并保留位置/旋转/缩放。
- **画布 Gizmo（v9）**：选中配饰、灯光或骨骼后，单指拖动执行移动/旋转/缩放；顶部工具条切换模式与自由/X/Y/Z 轴；Metal 叠加层绘制红绿蓝三轴、箭头、旋转环与缩放方块。
- **专业灯光（v9）**：最多 8 盏灯，支持太阳、点光、聚光（范围、锥角、内外锥平滑衰减）与环境光；灯光作为场景物件可选中、在画布移动；天空/地面半球环境光、环绕漫反射、逐灯高光可调。
- **实时物理（v10）**：播放 VMD 时逐帧推进二级运动与刚体求解，暂停即冻结、拖拽跳帧自动重置，离线导出同样确定性演算。按骨名识别裙子、头发、飘带、翅膀、袖子、披风、垂布等链，按父级角速度继承、重力、风力、刚度、阻尼和最大摆角驱动；PMX 动态刚体（mode 2）按质量、线性/角阻尼、反弹、地面接触、同组外球体碰撞和关节弹簧求解并回写骨骼。配饰独立刚体链由角色中心骨骼世界旋转驱动。
- **刚体与 IK（v10 / v12.3）**：解析 PMX 显示枠、刚体与关节；运行时 CCD IK 按 PMX link 顺序迭代，增量在**父骨空间**合成，并按镜像后的 lower/upper 角度限制裁剪；膝/踝按铰链约束，不再侧翻或反折。设置页可开关实时物理、IK 与地面碰撞，并显示动态刚体/关节计数。
- **PMD / VPD（v10）**：新增 PMD 解析（Shift-JIS 头、16 位索引、双骨权重、PMD IK、材质、morph、显示枠、刚体/关节），转换到统一 PMXModel 管线；支持导入 VPD 静态姿势并套用到手动骨骼/表情通道。
- **音频口型（v10）**：导入动作音频后按 30 Hz 计算 RMS 包络，驱动名称匹配的嘴部顶点 morph；可调幅度并可与 VMD morph 叠加。
- **模型与视频导出（v10）**：导出当前帧烘焙蒙皮/顶点 morph 的 OBJ+MTL、原始贴图与未修改 PMX/PMD 副本、当前姿态 VPD；离线视频按 VMD 时间轴固定 30 FPS 逐帧离屏 Metal 渲染为 1080×1920 H.264 MP4，可合并动作音频。
- **渲染工作台（v8）**：画风预设、卡通阴影柔化/暗部抬亮/阴影色调/轮廓光、主光/补光、对比度/饱和度/曝光/暗角、描边与输出分辨率集中编辑。
- **离屏渲染图（v8）**：独立 Metal 渲染目标，支持 1080×1920、1440×2560、2160×3840、2048×2048，可透明背景、网格与骨骼线；不再回退为屏幕截图。
- **贴图导出（v8）**：按 PNG/JPG/BMP/TGA/DDS 原始文件复制到 `Documents/MMDStudio/Exports/Textures`，不转码、不压缩，并生成 `_manifest.txt` 清单。
- **日志（v8）**：按信息/警告/错误筛选、全文搜索、分类与来源显示、一键复制、合并上一轮日志后分享；新增人体骨骼绑定明细、视频检测覆盖区间和离屏渲染尺寸日志。
- **模型信息**：版本、顶点/三角面/材质/骨骼/变形/贴图数量、尺寸、解析警告、格式、IK 骨骼数、刚体/关节数。

## 操作

- 单指拖动：旋转视角；启用场景 Gizmo 且已选中物件时改为变换物件
- 双指拖动：平移目标点
- 捏合：缩放
- 双击：重置相机
- 顶部画风条：MMD 标准 / 原神 / 星穹铁道 / 绝区零 / 写实一键切换
- 顶部场景条：移动 / 旋转 / 缩放、自由与 X/Y/Z 轴、关闭 Gizmo
- 底部命令栏：材质、贴图、表情、骨骼、灯光、相机、渲染、场景、设置、重置、骨架、拍照、录制
- 底部播放栏：播放/暂停、进度、循环、速度、相机动作、更换 VMD/ZIP

## 目录结构

```
MMDStudio/
├── MMDStudio.xcodeproj
├── MMDStudio/
│   ├── App/                 # App 入口、文档状态、模型库
│   ├── Core/                # PMX/VMD 解析、数学、动画、贴图
│   ├── Render/              # Metal 渲染器、网格构建、着色器
│   ├── UI/                  # SwiftUI 页面与 Inspector
│   ├── Assets.xcassets
│   └── Info.plist
└── README.md
```

主要类型：

- `MMDStore`：模型库、文件夹/单文件导入。
- `MMDModelDocument`：当前模型、材质/Morph/骨骼编辑状态、VMD 播放。
- `PMXParser` / `VMDParser`：二进制解析与坐标转换。
- `MMDSkeleton` / `MMDMorphController`：骨骼世界矩阵、蒙皮 palette、Morph 顶点位移。
- `MMDMeshBuilder` / `MMDRenderer` / `Shaders.metal`：Metal 资源、渲染通道与着色。

## 坐标与格式约定

- PMX 为左手坐标系；加载时顶点位置、法线、Morph 偏移的 Z 取负，转为右手系。模型正面朝 +Z，默认相机在 +Z。
- VMD 四元数 `(x,y,z,w)` 转为 `(-x,-y,z,w)`，位移 Z 取负。
- 三角形绕序不信任导出器：按面法线与顶点法线的一致性自动翻转，并按整体得分设置 `MTLWinding`。
- 渲染顺序：渐变背景 → 可选网格 → 柔和接触阴影 → 不透明材质（Alpha 裁切）→ 反壳描边 → 透明材质（按材质中心到相机距离排序）→ 骨骼线框。

## 示例资产

本版本不内置示例模型或动作，避免安装包携带占位资产。请导入自己的 PMX 文件夹与 VMD/视频动作。

## 当前限制

- 刚体/关节使用紧凑的 Bullet 近似求解，不是逐位复刻 Bullet；柔软体仅按骨骼链弹簧近似，未实现 PMX 2.1 逐顶点软体。
- IK 为运行时 CCD 迭代，按 PMX link 顺序与角度限制裁剪；未与 MMD 原版逐帧比对。
- VPD 已支持；VPV 不是 MMD 标准数据格式，本项目不解析 `.vpv`。
- 音频口型是 RMS 包络驱动的顶点 morph，不是音素级唇形同步。
- SDEF 按 BDEF2 近似；材质 Morph、UV Morph、骨骼 Morph 会解析但暂不参与渲染。
- VMD 相机姿态为近似实现，忽略 roll；未与 MMD 原版逐帧比对。
- 光照使用半球环境光、环绕漫反射与逐灯高光，不包含完整路径追踪或硬件光线追踪；聚光灯为实时锥角衰减。
- 配饰自动识别是保守启发式：明确的武器/配饰关键字优先，其次才按“无人体骨且顶点数较小”判断；误判时可在场景页解绑或移出。
- 模型导出为 OBJ+MTL（当前姿态）、原始 PMX/PMD 未修改副本与 VPD；不做 PMX 重写，OBJ 不携带骨骼/IK/刚体/材质 morph。视频导出固定 1080×1920、30 FPS、H.264，无透明通道。

## 故障排除

- **启动后模型库为空**：这是正常行为，本版本不再附带示例模型；请从「文件」App 导入 PMX 文件夹。
- **模型黑屏 / 无画面**：检查 `Shaders.metal` 是否在 target 的 Compile Sources；查看 Xcode 控制台是否有 Metal pipeline 创建失败日志。
- **贴图丢失**：优先导入整个模型文件夹；PMX 内的 Windows 绝对路径会回退到文件名匹配，并做大小写不敏感查找。
- **真机无法安装**：设置 Team 与唯一 Bundle Identifier；确认设备系统版本 ≥ iOS 17。

## v11.0 / v11.1 变更

v11.0：

- 暂时移除“从视频生成动作”入口与 `VideoMotionView` 编译引用；视频导出不受影响。
- 压缩包默认只导入一个主模型（体积最大的 PMX），其余模型在画布/设置中逐个添加；新增 `importAllModels`、`autoAttachPackageModels` 两个持久化开关。
- 实时物理不再把刚体位移回写到足、腿、膝、踝、脊柱、手臂、手、头颈等人体主骨。
- 贴图缓存改为按实际文件绝对路径索引，取消模糊前后缀猜测，避免跨模型串图。
- VMD 增加被 15 字节截断的 Bip001 别名，并忽略裙摆、头发、袖子、道具、`Ctr_`、`Skn_` 等控制骨轨道。
- 主页模型库增加运行日志入口。

v11.1：

- 修复 Shift-JIS 文件名被按 GBK 解码后的贴图丢失。例如 PMX 引用 `tex\体.png`，压缩包内实际文件名是 `tex\懱.png`；现在会通过代码页反推生成别名并唯一匹配。
- 贴图索引遇到一个别名对应多个文件时直接判为歧义并丢弃，仍不会跨模型串图。
- 贴图导出复用同一套别名解析，“缺失”列表会正确识别这些文件。
- 版本号 `11.1` / build `14`。

## v11.2

- 修复离线 MP4 上下颠倒：移除写入 CVPixelBuffer 时多余的垂直翻转。
- 物理修正：只驱动二级骨骼链的根节点，VMD 已有轨道的布料/头发骨骼不再叠加物理旋转；改用临界阻尼低通，避免每帧累积后撞上限。
- 刚体增加回到绑定位的弹簧，重力改为与 MMD 尺度匹配的 2.2g 等效，位移反馈上限从 1.2 降到 0.30。
- 人体主骨过滤补充腰、体幹、脚、もも、すね、かかと等日文命名。
- 视频导出支持手动分辨率与帧率（64–4096、1–120 FPS），可输出 HEVC Alpha `.mov` 透明视频。
- 场景增加背景图片导入，实时画布与离线渲染都使用同一背景。
- 材质、贴图、表情、骨骼、灯光、相机、场景面板改为半屏，编辑时保留画布预览；面板打开时顶部出现进度条，拖动即关闭面板回到全画布预览。

## v11.3

- 物理拆成三种模式：关闭（默认）/ 摆动（裙/发）/ PMX 刚体。默认不再开启，导入模型先确认摆动效果再决定是否用刚体。
- 物理与 IK 彻底解耦：所有 IK 链骨骼（IK 骨、目标骨、link 骨）与人体主骨不再被物理写入，因此不再需要为了稳定而关掉 IK 求解。
- 摆动改为世界坐标下的重力目标角 + 弹簧阻尼积分：骨骼朝地面下垂，并随身体转动产生惯性摆动，最大摆角按骨骼类型收紧（裙 14°、发 11°、翼 18°），超限自动回零。
- 刚体模式跳过 IK 骨与人体主骨，位移反馈按最大摆角收紧到 0.10–0.40，重力倍率从 2.2 降到 1.7。
- 实时画布每次绘制都显式清屏并清深度（不再依赖 MTKView 的默认 descriptor），避免上一帧残留被误认为“每帧叠加”。
- 分享面板改用 `.sheet(item:)` 携带非空 `SharePayload` 再构建 `UIActivityViewController`，首次点击不再出现空白分享框；同时补上 popover 锚点。
- 版本号 `11.3` / build `16`。

## v11.4

- 透明视频逐帧残影：写 CVPixelBuffer 前先 `clear` 并改用 `.copy` 混合模式。此前池化缓冲里的上一帧像素不会被覆盖，透明区域叠加后表现为“旧帧一直在新帧下面”。
- 视频画质：新增画质档（省空间/标准/高质量/极高）、手动码率（Mbps，0 为自动）、关键帧间隔（1–10 秒），导出面板显示实时码率与预估体积。
- 性能：离屏视频渲染改为 1× 采样（不做 MSAA），渲染目标纹理按尺寸缓存复用，取帧改为同步主线程调用去掉每帧的异步往返；4K 下这三项是主要瓶颈。
- 导出工作室新增“渲染当前帧 PNG”，按视频分辨率与透明设置出图，PNG 保留 alpha，不经过相机拍屏。
- 移除画布工具栏的“拍照”“录制”入口，渲染统一走导出工作室。
- 物理摆动增加躯干圆柱软避让：骨骼末端落入躯干半径时把目标角降到 45%，减轻裙/发穿模。
- 版本号 `11.4` / build `17`。

## v11.5

- 透明视频首帧：每帧写 CVPixelBuffer 前整块 memset 清零（含 alpha），并用 `.copy` 合成；首帧不再从缓冲池取旧内存。另加透明帧 alpha 覆盖率日志，便于确认首帧是否真的有残留。

## v12.7

物理系统整体重写。上一版是"给每片裙子的**第一根骨**加一个 ±14° 的正弦摆动"，
所以不管怎么调参数，布料都只是整片绕腰硬转 —— 就是"硬纸片"的来源。

- **每一节链骨独立积分。** 求解器现在维护每根布料骨的角速度和**世界朝向**，
  对重力、风力、身体拖拽分别施加力矩，再做一次锥角约束与碰撞。父骨的运动通过
  世界变换传给子骨，末端天然滞后，所以裙摆会弯成弧线而不是一块平板。
  实测（数值仿真）：走路 3 单位/秒时四节裙骨的偏角依次为 20°/37°/50°/57°，
  停止后收敛到 34°，是连续的曲线。
- **修复"静止时物理完全不动"。** 旧算法用 `acos(dot(骨骼方向, 重力))` 当目标角，
  而裙骨本来朝下，这个值恒为 0 —— 站着时无论重力调到多大都没有任何力矩。
  现在重力是真正的力矩（`cross(dir, down)`），水平时最强、垂直时为零。
- **修复"开了物理更穿模"。** 旧代码把带刚体数据的骨骼整批从摆动求解里排除，
  不管当前模式是不是"PMX 刚体"。所以带刚体段（但刚体已损坏）的模型，选"摆动"
  其实一根骨都没动。现在只在刚体模式才走刚体，刚体段为空时自动回退到链式摆动。
- **新增碰撞。** 躯干 + 左右大腿 + 左右小腿共五个胶囊体，按骨骼实时位置更新。
  当某根骨的悬挂点本身就在胶囊内（例如裙根埋在胯部）时跳过该胶囊，
  避免把整条裙子朝外撑开。
- **摆角上限按骨型缩放。** 裙/飘带 ×2.1、翅膀 ×1.8、袖 ×1.6、头发 ×1.45，
  再按链深每节递增 12%。默认上限从 24° 提到 40°，滑杆范围放宽到 4–90°。
- **物理默认开启**，与 MMD 本体一致。
- **帧重绘不再打断布料。** 暂停或一个时刻被重绘多次时，求解器改为"只重新输出
  姿态、不推进时间"，之前这会让布料在每一帧闪回静止形状。
- **导出确定性。** 视频导出改用固定 1/fps 步长，同一段动画每次渲染结果一致，
  不会因为编码耗时抖动而让布料走向不同。
- **刚体模式修正。** 局部旋转反馈改为按父骨世界旋转共轭（原来乘的是父骨的
  *局部* 旋转，布料刚体因此朝反方向摆）；回位弹簧从 14 倍质量降到 1.6 倍，
  关节补上位置投影，不再把裙子拉成橡皮筋。
- 面板新增「布料骨骼（链）」计数；为零且刚体数也为零时直接提示该模型没有
  可驱动的布料。


## v1.7（版本号自本版起改为 1.x，安装包与设置页一致）

v12.7 的布料求解器走的是**角速度 + 锥角限制**：每节链骨独立积分角速度，然后
按「偏离静止方向不超过 maxAngle × 2.1」硬裁剪。问题在于**每一节都撞在同一个
锥面上**，整条链于是被钉成一条直线，从肩膀斜着支出去、再也不会回来 —— 截图里
那根像塑料板一样的飘带就是这么来的。这一版换成位置动力学。

- **Verlet 链求解器。** 状态从「每节的角度」改成「每个链节末端的世界坐标」：
  重力与风力作用在位置上，链长用距离约束保证不可拉伸，相邻节之间只按
  「作者弯角 + 摆角预算」限制**相对**弯折，再用一个很软的位置回弹把链拉回
  原剪影。于是静止时贴回身体、动起来滞后并甩出去，而不是整条一起转身。
  数值验证：45° 外张的四节裙链静止下沉 17°（可调「刚度」），横向拖动 3 单位
  后末端滞后 25°、0.4 秒收敛；重力 1.5 + 阻尼 0.1 的极端参数下不发散。
- **链检测改为「结构 + 名称」双通道。** 只会认骨名的老逻辑碰上 `Bip001
  Accessory 04`、`Bone.017` 这类命名就一根都找不到，于是"物理没效果"。
  现在凡是**子树里不含人体骨骼的悬挂骨**都算二级骨；同时用名字做加权，
  「頭髪」这种带「頭」的骨名不会被误判成头部。若整个 rig 一个人体骨名都没有
  （无法区分四肢与布料），自动退回纯名称匹配。
- **碰撞体扩到 11 个。** 躯干、头、脖子、左右上臂/前臂、左右大腿/小腿。
  飘带和袖子挂在肩上，没有上臂胶囊就会直接从手臂里穿过去。
- **贴在身体上的链节不参与碰撞。** 裙根本来就埋在胯部胶囊里，推出去会把整条
  裙子撑开；改为按**静止位置**判断，只推那些本来在身体外的链节。
- **扭转让位给骨轴。** 骨骼旋转改成「在父骨空间里把静止方向最短弧转到解算方向」，
  扁平飘带不会绕自身轴乱翻。
- **诊断可见。** 设置页「物理系统」显示：布料链/骨骼数、碰撞胶囊数、链类型
  统计（skirt/hair/ribbon…）与前 8 条链的起点骨名；实时画布右上角显示
  `v1.7 (17)`，和安装包文件名一致，装错包一眼能看出来。
- 版本号从 12.x 改为 **1.7 (17)**：用户设备上装的是 1.6，此前 12.x 的编号
  与实际安装不一致，无法判断测的是哪一版。

## v1.8

v1.7 的链式解算方向对了（衣服确实动起来了），但暴露了三个工程问题：

- **分叉被压平，裙子被撕成尖刺。** 上一版把一个"悬挂子树"按 BFS 摊平成一条链，
  于是左右相邻的两片裙板、同一根发根下的两根发丝之间都被加上了距离约束 ——
  它们本来没有骨骼连接，约束只会把它们往反方向扯。截图里那条从裙子横向飞出
  的蓝色尖刺就是这么来的。现在链是**路径**：只有当某根骨是其父链的**当前末端**
  时才接上去，否则另起一条链、挂在父骨上；链按树深度排序，父链先解算，子链的
  锚点用父链解算后的世界变换，所以挂在裙骨上的发丝会跟着裙子走。
- **手臂/腿被当成布料甩。** 人体骨名表只有日文和英文，中文 rig 的「大臂 / 小臂 /
  肘 / 腕 / 大腿 / 小腿 / 膝」一个都不在里面，整条胳膊被判定为"悬挂骨"进了解算。
  补齐了 臂/肘/腕/手/掌/腿/膝/脚/踝/胯/胸/腹/脊/脖/颈/锁骨 等中文名。
- **刘海乱飞。** 「刘海 / 前髪 / bang」现在列入**刚性名单**，不进任何链 —— MMD
  本体里刘海也是焊在额头上不动的。
- **安全限幅。** 每个链节偏离静止位置不得超过自身长度的 1.45 倍。正常摆动碰不到
  这条线，但一帧异常（锚点瞬移、碰撞体弹出）不会再甩出一根永不回位的尖刺。
- **动作幅度上调。** 默认重力 0.6 → 0.75、最大摆角 40° → 50°，裙/发的回弹刚度
  下调（更松），实测比上一版明显。
- **2160p60 只有 30 帧：原因是编码器不是渲染器。** Apple 的 H.264 硬件编码器在 4K
  上封顶 30 fps（High profile level 5.1），请求 4K60 会被悄悄降成 30。现在按
  像素率选编码器：超过 1080p 或超过 30 fps 一律走 HEVC，H.264 只留给 1080p30。
  导出日志新增一行 `Export timing: x ms/frame render, y ms/frame encoder wait`，
  下一轮如果还慢，能直接判断是 GPU 还是编码器。
